# Yuefeng's To-Do

A simple to-do app.

## Existing Features

- View to-do items
- Add to-do items
- Mark items as complete
- Delete to-do items
- Set deadlines
- Sort by deadline
- Mark all items as complete with one click
- Clear completed items

## Planned Features

- Edit to-do items
- Keep to-do items after refreshing the page
